# YTDLP Studio Runtime

Public runtime components for YTDLP Studio. This repository contains no application source code.

Release archives contain the platform-specific FFmpeg, FFprobe, aria2c and yt-dlp components used by the desktop application. The optional libmpv player runtime is included where a portable package can be produced safely.

Run **Actions → Build Runtime Components → Run workflow** and enter a release version to publish Windows x64/ARM64, macOS Intel/Apple Silicon, and Linux x64/ARM64 runtime archives.
